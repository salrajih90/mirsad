# mirsad-site — حزمة نشر «المرصد المالي والاقتصادي»

مجلد جاهز للرفع إلى أي استضافة ثابتة. محتواه:

| الملف | الوظيفة |
|---|---|
| `index.html` | البوابة كاملة — مستند HTML واحد مكتفٍ ذاتياً (2.1 ميجابايت). مكتبة الرسوم وكل البيانات مدمجة داخله. |
| `_headers` | ترويسات الأمان والتخزين المؤقت (تقرأها Cloudflare Pages وNetlify تلقائياً). |
| `robots.txt` | يسمح بالفهرسة. |

## الرفع إلى Cloudflare Pages

1. افتح `dash.cloudflare.com` ← **Workers & Pages** ← **Create** ← **Pages** ← **Upload assets**
2. اسم المشروع: `mirsad`
3. اسحب هذا المجلد كاملاً (لا الملف وحده) وأفلته
4. الرابط الناتج: `https://mirsad.pages.dev`

لتحديثه لاحقاً: **Create new deployment** في المشروع نفسه، ثم أفلت المجلد المحدَّث. الرابط لا يتغير.

## من أين يأتي `index.html`

يُنتَج آلياً من عدّة البناء في `قاعدة البيانات/مصنع اللوحة/`:

```bash
python3 merge.py && python3 build3.py     # ينتج mirsad.html (جزء صفحة، صيغة أداة Artifact)
python3 wrap.py mirsad.html index.html    # يلفّه في مستند HTML كامل صالح للاستضافة
```

الفرق مهم: `mirsad.html` بلا `<!doctype>` ولا `<head>` لأن أداة Artifact تضيف الهيكل عند النشر. أما `index.html` فمستند كامل يحمل ترميز UTF-8 و`viewport` للجوال و`lang="ar" dir="rtl"` وأيقونة التبويب وبطاقة المشاركة — وبدون ذلك تُفتح الصفحة في وضع التوافق (quirks mode) وتظهر مصغّرة على الجوال.

## تحذير

لا تحرّر `index.html` يدوياً — أي تعديل يُمحى عند إعادة البناء. التعديلات تكون في ملفات العدّة.
