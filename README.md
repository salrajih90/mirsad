# mirsad-site — الموقع المنشور لبوابة «المرصد المالي والاقتصادي»

**الرابط الدائم:** https://mrsdx-fo.net
**الرابط الاحتياطي:** https://almirsad.pages.dev — يبقى عاملاً ولا يُلغى

## كيف يُنشر — تلقائياً بالكامل

```
المهمة المجدولة  →  تجلب البيانات وتبني وتتحقق
                 →  تنشر على رابط الـ artifact
                 →  wrap.py  →  index.html
                 →  deploy.sh  →  دفع إلى github.com/salrajih90/mirsad
                 →  Cloudflare Pages تبني وتنشر خلال دقيقة
```

لا خطوة يدوية في هذه السلسلة. لا تُعدّل ملفات هذا المجلد يدوياً — تُمحى عند إعادة البناء؛ التعديلات في `قاعدة البيانات/مصنع اللوحة/`.

## المحتوى

| الملف | الوظيفة |
|---|---|
| `index.html` | البوابة كاملة — مستند HTML واحد مكتفٍ ذاتياً. مكتبة الرسوم وكل البيانات مدمجة داخله. |
| `_headers` | ترويسات الأمان والتخزين المؤقت، تقرأها Cloudflare Pages تلقائياً. |
| `robots.txt` | يسمح بالفهرسة. |

## الإعداد القائم

- **المستودع:** `salrajih90/mirsad` (عام)
- **مشروع Cloudflare Pages:** `mirsad` — الفرع `main`، بلا أمر بناء، مجلد الإخراج `/`
- **الرمز:** fine-grained مقصور على هذا المستودع بصلاحية Contents فقط، **ينتهي 29/08/2027م**

عند اقتراب انتهاء الرمز ستتوقف الدفعات وتصلك رسالة من المهمة اليومية. التجديد: رمز جديد بالإعدادات نفسها، ثم النقر المزدوج على `احفظ-الرمز.command` في مجلد العدّة.

## نشر يدوي عند الحاجة

```bash
cd "قاعدة البيانات/مصنع اللوحة"
python3 merge.py && python3 build3.py
python3 wrap.py mirsad.html index.html
bash deploy.sh "$(pwd)/index.html"
```


## النطاق

| | |
|---|---|
| الدائم | `mrsdx-fo.net` — مسجَّل 30-08-2026م لدى Cloudflare، خوادمه `mallory` و`marek.ns.cloudflare.com` |
| الاحتياطي | `almirsad.pages.dev` — لا يُلغى؛ يعمل إن تعطّل النطاق أو حُجب عند مزوّد خدمة |
| المعياري | `wrap.py` يكتب `canonical` و`og:url` على النطاق الدائم في كل بناء |

**قيدٌ معروف على النطاقات حديثة التسجيل:** بعض محلِّلات مزوّدي الخدمة تحجب أي نطاق عمره أقل من ثلاثين يوماً، فيظهر للزائر `DNS_PROBE_FINISHED_NXDOMAIN` بينما النطاق سليم عالمياً. وهذا يزول بتقادم النطاق، والرابط الاحتياطي هو المخرج حتى ذلك الحين.
